# Wordle

*Финальное задание спринта 7 на Яндекс.Практикум*

Консольная реализация игры Wordle.

## 🎮 Как играть

- Угадайте слово из 5 букв за 6 попыток
- После каждой попытки показывается подсказка:
    - `+` — буква на своём месте
    - `^` — буква есть, но в другом месте
    - `-` — буквы нет в слове
- Пустая строка — подсказка от компьютера

## 🚀 Запуск

Запустите класс `Wordle.java`

## 📁 Файлы

- `words_ru.txt` — словарь (должен лежать в корне проекта)
- `game.log` — лог игры (создаётся автоматически)

## 🛠 Технологии

- Java 11+
- JUnit 5 (для тестов)
